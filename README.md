# 值班排班工具

面向小团队负责人的桌面端值班排班工具。使用 Electron 构建，可维护员工与班次信息，自动生成未来一至两周的排班表，并支持手动微调、冲突校验和 CSV 导出。

## 功能

- 员工管理：姓名、岗位、每周可工作天数上限、班次偏好、不可用日期。
- 班次配置：自定义班次名称、起止时间、当日最低在岗人数，并标记晚班。
- 自动排班：选择未来 1–14 天，一键生成整表。
- 排班规则：
  - 同一员工单日仅安排一个班次。
  - 连续上班不超过 5 天。
  - 晚班次日不安排早班。
  - 周末班次在团队成员间均衡分配。
  - 请假、外出等不可用日期自动跳过。
  - 无法满足最低人数时保留缺口，不强制填充。
- 排班表：日期为列、班次为行，周末列浅灰底色，缺口红字标注。
- 手动调整：点击单元格选择人员，即时校验规则冲突；冲突红色标示并悬停提示，不阻止保存。
- 导出 CSV：UTF-8 BOM 编码，可直接用 Excel 打开。
- 多方案管理：支持按月保存多份排班方案，切换查看、新建、复制、删除。
- 员工视图：员工仅查看自己未来的值班安排。

## 技术栈

- Electron
- 原生 HTML / CSS / JavaScript，无前端构建工具
- Node.js 内置测试运行器

## 环境要求

- Node.js 20+
- npm 10+

## 启动

```bash
npm install
npm start
```

## 测试

```bash
npm test
```

## 数据存储

应用状态自动保存到 Electron 的 `userData` 目录，文件名为 `shift-scheduler-state.json`。在浏览器中直接打开调试时，会回退到 `localStorage`。

## 目录结构

- `main.js`：Electron 主进程、窗口与文件读写。
- `preload.js`：安全地暴露状态读写与 CSV 导出能力。
- `scheduler.js`：可独立测试的调度与规则校验引擎。
- `renderer/`：界面、交互与渲染逻辑。
- `tests/scheduler.test.js`：调度引擎测试。

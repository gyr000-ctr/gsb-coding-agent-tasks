中间插删只改指向这两段的块，不整块复制字符串；顺便把 0 基的行列定位、撤销重做和事务一起做了。

块怎么写、长度按什么算、中间插入怎么切块、删除怎么削、长度 0 的块怎么处理、相邻同源的块什么时候
必须合并、行按什么切、行号列号是几基、结尾换行后面算不算空行、positionAt 和 offsetAt 怎么互逆、
每次编辑什么时候压撤销记录、replace 算几步、新编辑对重做栈做什么、transaction 怎么合并成一步、
事务里抛错怎么回滚、嵌套事务报什么、stats 六个字段各是什么、每种参数错报哪个码都写死了，照着来。
目录里 lib/errors.js、test 下两组用例、scripts/demo.mjs 都已经写好，就差 lib/pagetable.js，
别的文件不动，也别引第三方包。

容易写歪的地方：add 区只增不减——撤销和事务回滚都不许把它缩回去；块合并只在「同源且首尾相接」
时做，中间被删掉一段的两个同源块不算相接（它们的 start 差着删掉的那几个字符）；offsetAt 的列
是相对该行行首算的，行尾就是长度那个位置，超过才算越界，等于长度不算；undo/redo 空栈返回 false
而不是抛错；transaction 里啥都没改就别压撤销记录，抛错时撤销栈要跟事务开始前一样干净。

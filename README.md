# gridfit

一块内存里的小表格：格子要么放字面量、要么放 `=` 开头的公式；公式之间互相引用，
要按依赖顺序重算，环和错误值要往下游传。只用 Node 标准库，`node >= 20`。

```
gridfit/
├── lib/
│   ├── gridfit.js   createSheet 与解析 / 依赖图 / 重算           ← 还没实现
│   └── errors.js    GridError 与错误值清单
├── test/            sheet / edge 两组用例
├── scripts/demo.mjs 手工过一遍的演示脚本
└── package.json     npm test / npm run demo
```

```
npm test        # 11 条用例
npm run demo    # 打印下面那段固定输出
```

## 口径

### 地址

`A1` 这种写法：字母是列、数字是行，大小写不敏感（存进去统一大写），`$` 可以写但没意义（`$A$1` 就是 `A1`）。
列最多到 `ZZ`（702 列）、行 `1`..`999`；`A0`、`AAA1`、`A1000`、`a-1`、`A 1` 这些都不合法。

### 字面量格子

不是 `=` 开头的文本按这个顺序定型（先去掉首尾空白再判断）：

| 文本 | 值 |
|---|---|
| 空 / 全空白 | `null`（空） |
| `12` `-3` `1.5` `.5` `1e3` | 数字 |
| `TRUE` / `FALSE`（大小写不敏感） | 布尔 |
| 其它 | 去掉首尾空白后的文本 |

### 公式

`=` 后面跟表达式。运算符优先级从低到高：比较（`=` `<>` `<` `<=` `>` `>=`）< `&` < `+ -` < `* /` <
一元 `- +` < 括号；同层左结合。

- 字面量：数字、`"双引号字符串"`（里面用 `""` 表示一个引号）、`TRUE` / `FALSE`（大小写不敏感）。
- 单元格：`A1`；区间 `A1:B3`（**只能整个当函数的参数**，当普通值用就是 `#VALUE!`；两头反过来写也认，会自动取对角）。
- 函数：`SUM` `MIN` `MAX` `COUNT` `AVERAGE` `ROUND` `IF` `ABS` `LEN`，名字大小写不敏感；
  不认识的函数名是 `#NAME?`，参数个数不对是 `#VALUE!`。

取值规则：

- 算术 `+ - * /`：数字按数字、空当 `0`、`TRUE`/`FALSE` 当 `1`/`0`、文本是 `#VALUE!`；除数是 `0` 是 `#DIV/0!`。
- `&` 拼接：两边先转文本，`null` → 空串、布尔 → `TRUE`/`FALSE`、数字 → `String(v)`。
- 比较和判等：值分成四类，顺序是「空 < 数字 < 文本 < 布尔（`FALSE` < `TRUE`）」，跨类别就按这个顺序比，
  所以 `1 < "a"` 是 `TRUE`、`"3" > 3` 是 `TRUE`、`1 = "1"` 是 `FALSE`；同类别里数字比数字、文本按码元比。
  **空单元格跟 `0` 不是一回事**：`空 = 0` 是 `FALSE`、`空 = ""` 也是 `FALSE`，想当数字用就得放进算术里。
- `IF(条件, 甲, 乙)`：条件是 `FALSE` / `0` / `空` / `""` 时为假，其它（包括任意文本）为真；
  **只算走到的那一边**，所以 `IF(FALSE, 1/0, 5)` 是 `5`。
- `ROUND(x, d)`：`d` 必须是整数，按**二进制浮点**做「半进位朝远离 0 的方向」，`d` 可以是负数
  （`ROUND(1234, -2)` 是 `1200`）。
- `ABS(x)`、`LEN(x)`：`LEN` 数的是转成文本以后的长度（码元数）。
- `SUM` / `MIN` / `MAX` / `COUNT` / `AVERAGE`：参数是**单元格或区间**时只数数字，文本 / 布尔 / 空跳过；
  参数是**直接写死的字面量**时，数字算数字、`TRUE`/`FALSE` 算 `1`/`0`、文本是 `#VALUE!`。
  `MIN` / `MAX` 一个数字都没有是 `0`，`AVERAGE` 一个数字都没有是 `#DIV/0!`。

### 错误值

错误值是**字符串**：`#ERROR!`（公式写坏了 / 解析不过）、`#NAME?`、`#REF!`（引用越界）、
`#VALUE!`、`#DIV/0!`、`#CYCLE!`。任何一个值只要等于这几个字符串就按错误值处理，遇到错误值就整格
变成它（先算到的那个错说了算），`SUM` 里有一个错整格就是那个错。

### 重算

- 每次 `set` / `clear` 之后整块表重算，算出来的值不依赖 `set` 的先后顺序。
- 环上的格子（自己引用自己、几个格子互相引用）是 `#CYCLE!`，引用到环上的格子也跟着 `#CYCLE!`；
  把环拆掉（改一格）就恢复正常。
- `set` 传 `''` 等于把格子清掉（回到空）；`clear` 之后这格不再是「出现过的格子」。

### 抛错的地方

| 错误码 | 什么时候抛 |
|---|---|
| `ERR_BAD_ADDRESS` | 地址参数不是合法地址（包括不是字符串） |
| `ERR_BAD_ARGUMENT` | `createSheet(cells)` 的 `cells` 不是普通对象、格子内容 / `set` 的文本不是字符串 |

## API

| 入口 | 说明 |
|---|---|
| `createSheet(cells = {})` | `cells` 是「地址 → 文本」的对象；不传就是空表 |
| `set(address, text)` | 写格子（`''` 等于清掉），返回表格本身，可以连着写 |
| `clear(address)` | 把这格清掉，返回表格本身 |
| `get(address)` | 原文；没写过的格子是 `''` |
| `value(address)` | 算出来的值：数字 / 文本 / 布尔 / `null` / 错误值字符串 |
| `addresses()` | 出现过的地址，**先按列（A..ZZ）、同列再按行**排序 |
| `snapshot()` | 对象，键按 `addresses()` 的顺序，值是 `value()` |

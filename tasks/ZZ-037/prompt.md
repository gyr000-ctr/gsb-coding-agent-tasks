订阅制的账要按自然月摊钱，价格还老变，出了账之后才发现某个价格段生效时间写早了，得能倒回去改账、把多收的退掉少收的补上。想在这仓库里把这套计费写出来。

入口一个 createInvoicer，README 的《口径》和《API》两节把套餐和有效日期价格段怎么算、订阅期怎么校验、出账区间怎么切、每条行怎么舍入、金额汇总口径、改价之后哪些账单要失效、失效的怎么重算和调账、账号汇总怎么取、统计口径、每种错误报哪个码都写死了，照着来。目录里 lib/errors.js、test 下两组用例、scripts/demo.mjs 都已经写好，就差 lib/invoicer.js，别的文件别动，也别引第三方包。

几个我特别在意的地方。切片的依据是自然月加价格段边界，两个都要切到：一个月中间改价，那一月就得拆成两行。片段的金额是按这个自然月的实际长度摊的，闰年的 2 月是 29 天，别写成固定 30 天或 28 天。舍入的口径是每条行先四舍五入到分，再把各行加起来，不是先加总最后才舍入。

追溯改价只把受影响的账单标成待重算，账单上的金额先别动，等 rebill 的时候才算新账、出补收或者退款；把价格改回去的话，待重算的状态也应该撤掉。已经出过的区间不能再出一次，部分重叠也要拦住。

跑法两条：npm test 全绿（12 条，里面有整月切片、月中按月长摊与四舍五入、闰年 2 月、月中改价的二次切片、rebill 的补收与退款、stale 与恢复、账号汇总、租用期与重叠校验、没有价格、各条参数与错误码），npm run demo 的输出跟 README 最后贴的那段一行行对上。

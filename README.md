# 值班排班工具

面向小团队负责人的桌面端值班排班工具。排班表以日期为列、班次为行，支持自动排班、规则校验、手动调整、员工个人视图和 CSV 导出。

## 运行方式

环境要求：已安装 Python 3（本工具不依赖第三方包，也不需要 Node.js）。

```bash
python3 app/run_server.py
```

启动后会自动打开浏览器窗口。若浏览器没有自动打开，可手动访问终端中显示的 `http://127.0.0.1:8765/index.html` 地址。

## 功能

- 员工管理：岗位、每周可工作天数上限、班次偏好、请假/外出等不可用日期。
- 班次配置：自定义班次名称、起止时间、当日最低在岗人数；默认提供早班、中班、晚班。
- 自动排班：选择未来 1 至 14 天，一键生成整表。
- 规则校验：单日单班次、连续上班不超过 5 天、晚班次日不排早班、不可用日期跳过。
- 均衡分配：周末班次优先在成员间均衡分配，并兼顾总排班量和班次偏好。
- 缺口提示：无法满足最低人数时不强制填充，单元格红色显示缺口人数。
- 手动调整：表格内可直接增删人员，调整后即时校验；冲突单元格变红，悬停显示违规原因。
- 方案管理：按月份保存多份排班方案，随时切换查看。
- 员工视图：仅展示指定员工后续值班安排。
- 导出 CSV：带 UTF-8 BOM，可直接用 Excel 打开。

## 数据存储

所有数据保存在浏览器 `localStorage` 的 `dutyPlannerState.v1` 键中。由于不同端口/域名下的存储相互独立，请固定使用启动器提供的本地地址。

## 文件说明

- `app/index.html`：应用页面外壳。
- `app/styles.css`：界面样式。
- `app/app.js`：排班、校验、方案管理、CSV 导出等核心逻辑。
- `app/run_server.py`：零依赖的本地静态服务器和浏览器启动器。

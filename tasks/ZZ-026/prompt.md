下载站要把私有文件发出去，链接得带签名和过期时间，别人改一个字符就失效，现在这块还没写。

入口一个 createLinkSigner，README 的《口径》和《API》两节把签名素材怎么拼、路径和查询串怎么规范化、过期时间怎么算、签名取多长、sign 和 verify 各按什么顺序检查、每种错误报哪个码都写死了，照着来。目录里 lib/encode.js、lib/errors.js、test 下两组用例、scripts/demo.mjs 都已经写好，就差 lib/link.js，别的文件别动，也别引第三方包。

两边算签名必须一模一样：路径要先解一次转义再按段重编码（不能编两遍），查询串按键再按值排序，空值写成 k=，方法统一大写，"现在几点"只能从 clock 拿，别在代码里偷偷 Date.now()。

verify 的顺序不能乱：先看 url 合法不合法，再看 e 和 s 在不在、e 是不是整数秒，然后判过期（正好到点那一刻就算过期），最后才比签名；s 自己不参与签名素材，算之前要摘掉。签名按字节比，别用 === 短路。

跑法两条：npm test 全绿（13 条，里面有路径和参数写法归一、同名参数排序、重新签覆盖旧参数、过期边界、缺参数和换钥匙），npm run demo 的输出跟 README 最后贴的那段一行行对上。

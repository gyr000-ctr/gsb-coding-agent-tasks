tplate 这个小模板引擎现在是能用的那一版：插值（默认过 HTML 转义）、{{#x}}…{{/x}} 段落、注释、
上下文栈，test/tplate.test.js 那 9 条一直是绿的，这次别改坏。现在要往上加一版：不转义的插值、
反向段落、点路径、片段和缩进，还有标签独自占一行时的空白处理。

同事把这次的验收用例先写好放在 test/tplate2.test.js 了，9 条现在红了 7 条，demo 也还跑不到
README 最后贴的那段输出。README 的《现在的口径》和《这次要加的》两节就是标准答案，照着来。
目录里 lib/errors.js、test 下两组用例、scripts/demo.mjs 都已经写好，只动 lib/tplate.js，
别的文件别改（用例是标准，别改用例去迁就实现），也别引第三方包。

要加的东西都在《这次要加的》里：{{{x}}} 和 {{&x}} 不转义；{{^x}}…{{/x}} 反向段落（假值和空数组
才渲染，而且渲染时上下文不换）；{{a.b.c}} 点路径（先在有 a 的那层上下文里找到 a，再顺着 b、c
往下取）；{{> name}} 片段（第三个参数 options.partials 是「名字 -> 模板字符串」，用当前上下文
渲染、能再套片段、找不到就什么都不输出）；片段的缩进（标签前面那段空白贴在片段渲染结果的每一行
行首）；还有独立行的空白规则（#、^、/、!、> 这几种结构标签独自占一行时，整行连缩进带换行一起
删掉，插值标签和「一行里还有别的东西」都没有这个待遇）。

容易写歪的地方：转义只对 {{x}} 生效，{{{x}}} 和 {{&x}} 原样吐；反向段落里别把那个假值压成新
上下文，{{^x}}{{name}}{{/x}} 取的是外层的 name；点路径是「从里往外找第一个有第一段键的上下文，
找到以后剩下的路径断了就是没取到」，别退回更外层接着找（这是它跟 v1 那种「整个名字当一个键」
最不一样的地方）；片段的缩进是贴到片段**自己渲染出来的**每一行行首（片段里多行都要贴），渲染
结果正好以换行结尾时最后那个空行不贴；独立行判定要求这一行除了这个结构标签就只有空白（空格 /
制表符），文件最后一行没有换行也算；找不到的键、找不到的片段都还是空串，别改成报错；老的错误码
和口径（不合法名字、没闭合、多出来的结束标签、模板 / 数据 / partials 的入参类型）保持原样。

口径），npm run demo 的输出跟 README 最后贴的那段一行行对上。

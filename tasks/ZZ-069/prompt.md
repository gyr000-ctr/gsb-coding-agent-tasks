容易写歪的地方：空单元格是 null，但 null 在算术里当 0、在 & 里当空串、在比较里自己一类（空 < 数字 <
文本 < 布尔），所以「空 = 0」和「空 = ""」都是 FALSE；typeof null 是 object 这个坑会让空引用被当成
「区间对象」直接报 #VALUE!，实现里得把「区间」和「空」分清楚；区间只能整个当函数参数，写成
=A1:A2+1 是 #VALUE! 不是数组运算；SUM 这些收引用 / 区间时文本、布尔、空都要跳过，但直接写
SUM("x") 是 #VALUE!、SUM(TRUE) 是 1；AVERAGE 一个数都没有是 #DIV/0! 而 MIN/MAX 是 0；IF 只算
走到的那一边（IF(FALSE,1/0,5) 是 5），条件里的空和 "" 跟 0 一样算假；公式解析不过是 #ERROR!、
函数名不认识是 #NAME?、引用越界（列超过 ZZ 或行超过 999）是 #REF!，别混着用；环上的格子标 #CYCLE!
并往依赖它的格子传，把环拆掉得能自己恢复；重算结果不能依赖 set 的先后，两种顺序建出来的表 snapshot
必须一模一样；addresses / snapshot 是先列后行的顺序（A2、A10、B1、AA1、ZZ999 这样），不是字典序；
地址参数连 $A$1 都认，但不合法的（A0、AAA1、A1000、不是字符串）一律 ERR_BAD_ADDRESS，格子内容
不是字符串是 ERR_BAD_ARGUMENT。
